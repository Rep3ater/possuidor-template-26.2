# Requiem 1.21.11 integration checkpoint

The Requiem project now targets Minecraft 1.21.11 and NeoForge 21.11.48. Parmenides is integrated into the Requiem source set, with its scoreboard role marker and generated projection entity-type tag. The broader cross-dimensional projection, input switching, damage routing, and client rendering behavior is still in progress.

Run `gradlew build` to check the integrated project and `gradlew runData` to generate registry tags.
